cd C:\MyAI\dm-converter\backend
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000

Да, если я остановлю сервер, приложение перестанет открываться. Причина простая:

Сервер — это обычный процесс (python -m uvicorn app.main:app), который я запустил в фоне. Пока процесс жив — он слушает порт 8000 и отвечает браузеру: отдаёт страницу, PDF, принимает файлы. Если процесс убить — порт 8000 освобождается, и по адресу http://localhost:8000 никто не отвечает: браузер покажет «сайт недоступен / ERR_CONNECTION_REFUSED».

Это не часть самого приложения — приложение это просто код в backend/ и frontend/dist. Он ничего не «делает», пока его кто-то не запустил. Поэтому:

- Сейчас — процесс держит моя фоновая задача, он живёт, пока я его не остановлю или не завершится сеанс.
- Когда захочешь запустить сам — это одна команда в терминале:

cd C:\MyAI\dm-converter\backend
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000

После этого открываешь http://localhost:8000 — работает так же. Закроешь терминал (или Ctrl+C) — сервер снова остановится. Это нормально для локальной разработки: запускаешь, когда нужно пользоваться.

Если же нужен постоянно работающий сервис (чтобы открывался всегда, без ручного запуска) — для этого есть варианты посложнее: автозапуск через планировщик задач Windows, сервис через nssm, Docker-контейнер и т.п. В README я описал этот вариант деплоя. Скажи, если захочешь так сделать — настрою.

Так что останавливать не страшно: в любой момент всё поднимается одной командой. Оставить работающим или остановить?
